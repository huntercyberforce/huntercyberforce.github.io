# Hunter Cyber Force (HCF)

Static official website starter for Hunter Cyber Force.

## Publish free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `style.css` to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.

Before publishing, review all names, titles, dates and organization claims for accuracy.
